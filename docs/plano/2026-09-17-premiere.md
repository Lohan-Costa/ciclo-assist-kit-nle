# O Ciclo Assist no Premiere — plano de fases

**Data:** 2026-09-17 · **Alvo:** Premiere Pro **23.2** / Windows 11, na MESMA máquina do Avid ·
**Primeira entrega:** só leitura (P0–P5). Escrita (P6) e macOS (P7) depois.

## O pedido

> Trazer o Ciclo Assist para o Premiere exatamente como é hoje no Avid — painel CEP próprio,
> serviço na 7824, o Mac mini processando as mídias.
>
> Premissa a validar: "identificar material convertido para não reprocessar". No Avid o
> material vira Avid MediaFiles (MXF); no Premiere o item aponta para o original ou para um
> proxy dele. Os dois precisam casar com o mesmo registro já processado.

## A premissa, conferida antes de codar

**O registro NÃO mora no Mac mini.** `servidor_mac/siglip_servidor.py` e as duas specs do Mac
dizem o mesmo: entra quadro, sai vetor, e o quadro é esquecido; o Ollama idem. O que já foi
processado (quadros, fala, vetores, decupagem) mora no cache da máquina do serviço,
endereçado pelo UMID do master. Decisão do editor (2026-09-17): **o Premiere roda na mesma
máquina do Avid** ⇒ basta o Premiere achar o MESMO cache.

| no Premiere o item aponta para… | chave possível | casa com o que o Avid processou? |
|---|---|---|
| OP-Atom da `Avid MediaFiles` | `material_package_umid` (ffprobe) | ✅ é a chave de hoje |
| MXF de câmera (Sony/ARRI…) | UMID do arquivo | ✅ o Avid copia o UMID ao linkar (banco, `banco-de-midias-compartilhado.md` §1) |
| MOV / MP4 / BRAW / WAV | nenhum UMID | ⛔ no AMA a chave de hoje é o `mob_id` que o Avid GERA a cada link — é o defeito da fase C3 |
| original no Premiere, transcode DNxHD no Avid | UMIDs diferentes | ⛔ só por linhagem — **por medir** |
| proxy anexado (`attachProxy`) | `getMediaPath()` = original? | **hipótese** — por medir |
| proxy importado como mídia principal | outro hash | só por vínculo proxy→original |

⇒ A premissa só vale inteira quando a identidade por conteúdo existir dos DOIS lados. Por
isso a P1 vem antes do painel.

**A diferença de arquitetura:** no Avid o serviço fala direto com o MC (gRPC). No Premiere
não há API externa: `app.project` só existe dentro do painel, em ExtendScript. Toda
ferramenta que lê o projeto vai serviço → painel → ExtendScript → serviço.

## Fases

| fase | entrega | pronto quando |
|---|---|---|
| **P0 — sondas** | (a) o painel CEP carrega a página do serviço e o `evalScript` sobrevive; que `Origin`/`Sec-Fetch-Site` o CEP manda · (b) ffprobe nos tipos da tabela; `getMediaPath`/`getProxyPath`/`hasProxy` com proxy anexado; o transcode do Avid guarda o original? · (c) latência da ida e volta serviço → painel → ExtendScript | cada pergunta com número e data no banco |

| P6 — escrita | `separar_falas`, `montar_corte`, `editar_timeline` no Premiere | (depois da primeira entrega) |
| P7 — macOS | pasta de extensões, `PlayerDebugMode`, suíte no Mac | (depois) |

### P1 ✅ 2026-09-17 — a identidade de um arquivo

- `midia/identidade.py`: `chave_do_arquivo` (UMID do arquivo, senão a impressão do conteúdo:
  SHA-256 de tamanho + 4 MB do início + 4 MB do fim), `sondar` (o que identifica, guardado em
  `identidades.json` por tamanho:mtime) e `achar(arquivo)`: pela chave → pelo apelido → pelo
  convertido (candidato por metadado, confirmação por conteúdo).
- `midia/cache.py`: **apelidos**. Uma mídia tem uma pasta e várias chaves; `todas()` lista só
  as chaves; `com_apelidos()` traduz os `mob_id` das bins; uma chave de outra pasta nunca vira
  apelido (juntaria duas mídias).
- `avid/take.py`: o master AMA ganha `Fonte.chave` pela chave do arquivo. Três casos: o
  arquivo já tem pasta (o `mob_id` deste link vira apelido) · a pasta antiga é do `mob_id`
  (continua dona, o conteúdo vira apelido — **nada reprocessado**) · nada (nasce pelo
  conteúdo, com o `mob_id` de apelido). Todo consumidor usa `fonte.midia()`.
- O recorte por projeto (`escopo`) e a aba Vetores (`_clipes_conhecidos`) traduzem os apelidos.
- Som: o OP-Atom do Avid começa **398 amostras (8 ms)** depois do WAV, alinhado ao quadro;
  amostra a amostra são idênticos (correlação 1,000). A confirmação procura o pico com folga
  de 0,5 s. Piso 0,90.

**Conferido contra os pares reais** (cópia do cache, 2026-09-17):
