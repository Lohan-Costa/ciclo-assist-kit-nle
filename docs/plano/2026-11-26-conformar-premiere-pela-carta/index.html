O que sai do marcador

O modo Premiere do Conformar monta pela ponte (dlpcMontar). O que o ExtendScript não faz vira marcador "refazer". A Carta já traduz cada um desses itens, medida quadro a quadro.

Um caminho só

O dlpcMontar fica no código até as provas fecharem; depois sai. Marcador passa a existir só para o que a Carta diz que ficou de fora, com o motivo.
