## 3. O desenho de destino

```
_CICLO ASSIST/                      (o repositório — renomear a pasta é a fase 6)
├─ app/                             o guarda-chuva (Tauri): UMA janela, as abas, o supervisor dos motores
├─ cicloassist/
│  ├─ nucleo/                       o que é de todos: ponte do Premiere, mcapi, Resolve externo, token, portão,
│  │                                plataforma, cache de mídia, instalador de integrações, servidor HTTP base
│  ├─ modulos/
│  │  ├─ sincronizar/               ex-Órbita: motor (o src-python de lá) + servidor + página da aba + ferramentas
│  │  ├─ conformar/                 ex-De Lá Pra Cá
│  │  ├─ assistir/                  o chat (o que hoje é cicloassist/ inteiro, aos poucos)
│  │  └─ entregar/                  ex-Promo Entrega (quando vier)
│  └─ …
├─ integracoes/                     os plugins de NLE (UMA ponte Premiere, UM painel MC, o script do Resolve)
└─ tests/<modulo>/                  a suíte de cada módulo roda SOZINHA (o "não quebrar o outro")
```

**O contrato de um módulo** (o que torna "somar ferramentas" barato):

- um **processo próprio** (motor), subido e religado pelo supervisor do app — um módulo que cai não leva os outros
  (é o que o supervisor já faz hoje com os três motores);
- uma **porta** e uma **pasta de dados** dentro da do Ciclo Assist (`…/CicloAssist/<modulo>/`);
- uma **página** (a aba) servida pelo motor, com o contrato `?embutido=1` que já existe;
- **ferramentas do agente** registradas pelo módulo (o `escreve=` passa pelo portão — ADR 0008);
- **só o núcleo fala com o NLE**: o módulo pede ao núcleo ("chame `orbitaBuildSequence` no Premiere"), nunca instala a
  sua ponte. ⛔ É o que acaba com as três extensões no Premiere e com a classe de bug "a aba escondida parou de ouvir".
- **dependência só para baixo**: módulo → núcleo, nunca módulo → módulo. Um módulo usa outro pelo agente ou pela API
  dele (como o Assistir já usa o Sincronizar pela `/api/v1`).

- **A reescrita do servidor** perde comportamento que só o Rust tinha e que nenhum teste cobria (o portão de origem —

**Recomendação: reescrever o ESQUELETO, não o miolo.** Um esqueleto novo (o núcleo, o contrato de módulo, o app), escrito
do zero e sem herança; o miolo (o que fala com mídia e com os NLEs) entra nele MOVIDO, com os testes dele, peça por peça.

**Por que não do zero inteiro:**

- **O valor deste código não é o código, é o que foi MEDIDO.** São 1626 testes e dezenas de armadilhas que só se
  descobriram com o NLE na tela: o trio carregar→consultar→fechar que derruba o MC, a string nula do `.avb`, o fecho
  oculto da bin nova, o `allow_reuse_address` do Windows, o som multipista canal a canal, o LOG do BRAW, o `scrubTo` em
  tempo desde o início. Reescrever é pagar cada uma de novo — a família já registrou duas vezes a mesma armadilha
  redescoberta, e "a segunda implementação da mesma pergunta" é a forma de bug que o Órbita conhece (48ª/49ª).
- **O miolo não tem a forma do formato antigo.** `midia/` (cache por UMID, ASR, vetores, decupagem, cortes), `avid/`
  (pyavb fiel, mcapi, take, edição com prova), `nle/premiere/` (a ponte, o host.jsx), `plano/` (mapa, falas) e o portão
  do `mcp/` são o produto em qualquer desenho — nenhum deles sabe que um dia houve painel dentro do MC.
- **Do zero, o app fica parado semanas** (~50 mil linhas no `cicloassist/`); por migração, ele roda ao fim de cada fase.

**O que É herança, e é aí que o redesenho entra (o esqueleto novo):**

| herança | por quê | no desenho novo |
|---|---|---|
| `servico/` (8 mil linhas): um processo com três papéis, as rotas de tudo num lugar | nasceu como o serviço do painel do MC | cada módulo com o seu servidor; o núcleo dá a base (portão, `Sec-Fetch-Site`, no-store, porta ocupada) |
| `painel/` (8 mil): uma página com chat, busca, vetores e fluxos | era o painel de 400 px dentro do NLE | a aba Assistir é UM módulo; Busca e Vetores decidem onde moram (Assistir ou núcleo de mídia) |
| o "editor do turno" global (`nle` por pedido, persona e ferramentas por NLE) | painel dentro de UM NLE | o app vê os três NLEs (`/conexao`); o NLE é estado do núcleo |
| `cicloassist/orbita.py`, `delapraca.py`: clientes HTTP de outros apps | os módulos eram apps vizinhos | cada módulo REGISTRA as próprias ferramentas do agente; o Assistir não conhece o Sincronizar por dentro |
| `painel_cep/` (tela dentro do Premiere), o `.avpi` com interface, `--painel` | antes do "app único fora do NLE" (21/10) | **cortar**: só a ponte invisível, só o loader |
| `MUDANCAS DOS APPS/`, `INSTALAR.bat` de seis passos, os três instaladores de CEP | apps separados | **cortar** / um instalador no núcleo |

⇒ **Na prática, a fase 1 vira a fase do esqueleto:** antes de trazer o Sincronizar, escrever o núcleo e o contrato de
módulo, e fazer o Sincronizar (que nasce em Python de qualquer jeito) ser o PRIMEIRO módulo construído nele — ele prova
o contrato. O Assistir e o De Lá Pra Cá entram no esqueleto depois, movidos com os testes.

⚠️ O que se aceita perder com isso: nada do comportamento medido. O que se aceita reescrever: as rotas e as telas, que
mudam de forma de qualquer jeito.
